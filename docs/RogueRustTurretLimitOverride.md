# RogueRustTurretLimitOverride

> Configures Rust's turret interference ConVars.

**Version:** `2.1.1`

[Plugin source](../plugins/RogueRustTurretLimitOverride.cs) · [Back to plugin catalogue](../README.md)

## Features
- Configures Rust turret interference ConVars through a RogueRust plugin.
- Administrative command control.
- Persistent configuration through the standard framework config directory.

## Compatibility
Rust · Oxide · Carbon · RogueRust extension/framework

## Permissions
- `roguerustturretlimitoverride.admin`

## Commands
- `turretlimit`

## Configuration
The generated configuration stores the turret-limit behaviour. Keep the configuration when updating unless a release requires regeneration.

## Installation
Install RogueRust, place `RogueRustTurretLimitOverride.cs` in the plugin directory and grant the admin permission to the appropriate group.
