# RogueRustServerRestarter

> Schedules safe server restarts with RogueRust runtime protection, chat, game-tip, and GUI warnings.

**Version:** `2.1.0`

[Plugin source](../plugins/RogueRustServerRestarter.cs) · [Back to plugin catalogue](../README.md)

## Features
- Scheduled safe server restarts.
- RogueRust runtime protection.
- Chat, game-tip and GUI restart warnings.
- Administrative reload/test controls.

## Compatibility
Rust · Oxide · Carbon · RogueRust extension/framework

## Permissions
- `roguerustserverrestarter.admin`
- `roguerustserverrestarter.use`

## Commands
`serverrestart`, `serverrestart.reload`, `serverrestart.test`

## Configuration
Use the generated configuration to manage restart scheduling and warning behaviour. Retain it during upgrades unless release notes state otherwise.

## Installation
Install RogueRust and copy `RogueRustServerRestarter.cs` to the server plugin directory, then configure the restart schedule and permissions.
