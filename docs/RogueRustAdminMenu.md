# RogueRustAdminMenu

> RogueRust 3.3.5 administration workspace with F1-style RogueUI, native vehicle/item artwork, shared teleport/vehicle services and lightweight AdminVanishUncharted.

**Version:** `2.1.1`

[Plugin source](../plugins/RogueRustAdminMenu.cs) · [Back to plugin catalogue](../README.md)

## Features
- F1-style RogueUI administration workspace.
- Native vehicle/item artwork and shared RogueRust teleport/vehicle services.
- Lightweight AdminVanishUncharted support.
- Optional Discord/webhook integration where configured.

## Compatibility
Rust · Oxide · Carbon · RogueRust extension/framework

## Permissions
`roguerustadminmenu.convars`, `roguerustadminmenu.give`, `roguerustadminmenu.give.selfonly`, `roguerustadminmenu.groups`, `roguerustadminmenu.permissions`, `roguerustadminmenu.players`, `roguerustadminmenu.players.blueprints`, `roguerustadminmenu.players.heal`, `roguerustadminmenu.players.hurt`, `roguerustadminmenu.players.kickban`, `roguerustadminmenu.players.kill`, `roguerustadminmenu.players.mute`, `roguerustadminmenu.players.strip`, `roguerustadminmenu.players.teleport`, `roguerustadminmenu.plugins`, `roguerustadminmenu.use`, `roguerustadminmenu.vanish`, `roguerustadminmenu.vehicles`.

## Commands
`admin`, `vanish`

## Configuration
Configuration is generated under the normal Oxide/Carbon config directory. Current option names, defaults, validation and migrations are defined by the plugin source.

## Installation
Install the RogueRust extension/framework, then place `RogueRustAdminMenu.cs` in the server plugin directory and grant only the permissions required by your staff.

## Updating
Replace the `.cs` file with the newer revision while retaining configuration/data unless release notes state otherwise.
